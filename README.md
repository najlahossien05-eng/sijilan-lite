# حاسبة سِجلان

نسخة خفيفة من سِجلان لحساب توزيع الحصص: الاستقطاعات، وحصة مريم، وتوزيع الصندوق مناصفة، والعمولات البنكية، والمستحق للتحويل.

تطبيق ويب ثابت (HTML + JavaScript) بلا خادم وبلا خطوة بناء. كل البيانات تُحفظ على الجهاز (localStorage) ولا تُرسل إلى أي مكان.

## الشاشات

- **الحاسبة:** مبلغ عبدالعالم ومبلغ الإخوة (مع حاسبة لجمع عدة مبالغ)، وتفعيل حصة مريم، وتسلسل العملية خطوة بخطوة.
- **الأفراد:** حساب سريع لمبلغ فرد واحد.
- **المحفوظة:** كل عملية محفوظة، والمجموع المتراكم (هذا الشهر أو الكل)، ونسخة احتياطية.
- **الإعدادات:** الأسماء والنسب والعمولة والحصة الثابتة، وخط تقرير PDF.

## التقارير

- نسخ تقرير مختصر، أو تسلسل العملية كاملًا.
- تحميل PDF نصي بحجم A4 بجداول (الملخص، التسلسل، التحقق من التوازن)، أو مشاركته من الجوال.

## التشغيل

افتح المجلد عبر أي خادم ملفات ثابت، مثلًا:

```bash
npx serve .
```

ثم افتح الرابط في المتصفح. (فتح `index.html` مباشرة كملف يعمل، لكن PDF والعمل بدون إنترنت يحتاجان خادمًا.)

## الاختبارات

```bash
node --test calc.test.js
```

## الملفات

| الملف | الوظيفة |
|---|---|
| `calc.js` | قواعد الحساب (نفس معادلات التطبيق الكامل) |
| `app.js` | الواجهة والحفظ والتقارير النصية |
| `pdf.js` | إنشاء تقرير PDF |
| `sw.js` | العمل بدون إنترنت |
| `vendor/jspdf.umd.min.js` | مكتبة jsPDF (رخصة MIT، انظر `vendor/jspdf.LICENSE`) |
| `fonts/NotoSansArabic-*.ttf` | الخط الافتراضي للتقرير (رخصة SIL OFL، انظر `fonts/OFL.txt`) |
